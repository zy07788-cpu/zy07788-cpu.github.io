# 茶叶的实验室

个人介绍与作品展示：https://zy07788-cpu.github.io/

- 论文写作与排版 Skill：介绍、使用示例与公众号领取入口。

## 页面与工具

- `index.html`：个人介绍、四个作品入口及联系方式。
- `thesis.html`、`duck.html`、`drawer.html`：项目详情。
- `cover.html`：选择公众号封面或图文首页图编辑器。
- `tools/cover/index.html`：公众号封面，横版1880×800、方版800×800。
- `tools/poster/index.html`：图文首页图，竖版1440×1920或1440×2400、方版1080×1080。
- `privacy.html`：隐私说明。

封面工具支持上传图片、自选颜色和纸张/画布/淡彩/拼纸材质生成、PNG/JPG导出，以及方案JSON保存/载入。文字、图片与材质生成在浏览器本地处理；两类编辑器各自暂存草稿，不跨设备或浏览器同步。网站未接入实时模型生图API，不收集论文、图片或账号信息，也未加入第三方统计脚本；托管平台可能保留必要访问日志。
