- `thesis.html`、`duck.html`、`drawer.html`：项目详情。

- 原 `tools/layout/`、`tools/cover/`、`tools/poster/` 及子编辑地址保留迁移落地页。

- `tools/poster/index.html`：图文首页图，竖版1440×1920或1440×2400、方版1080×1080。
